# 📅 How to add an event to your website

A quick guide for adding and managing events in your Sanity Studio — no technical
knowledge needed.

## Adding an event

1. Go to **niamhpadma.com/studio** and log in.
2. Click **Events** in the left menu, then the **＋ / Create new** button.
3. Fill in the details. The grey hint under each box tells you what it's for. The
   ones that matter most:
   - **Title** — the event name.
   - **Slug** — click **Generate** (this becomes the page's web address).
   - **Start Date** — ⚠️ **use a future date**. If it's blank or in the past, the
     event won't show on your site (you'll see a yellow warning reminding you).
   - **Excerpt** — one or two sentences for the events list.
   - **Description** — the full write-up.
   - **Cover Image** — drag in a nice landscape photo, and add a few words of
     "Alt text".
4. Click the orange **Publish** button (bottom-right). When it changes to
   "Published", you're live. ✅
5. Check it at **niamhpadma.com/events** — your event appears, newest dates first.

## If an event doesn't show up

It's almost always one of two things:

- The **Start Date** is blank or in the past → give it a future date.
- It's still a **draft** → press **Publish**.

## Marking an event full or cancelled

Open the event and change **Status** to *sold-out* or *cancelled* — no need to
delete it. The website updates to match.
